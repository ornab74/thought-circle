# Thought Circle v1.0.0

Thought Circle is a calm, private journal and local AI guide for turning looping thoughts into clarity and small next steps.

## Features

- Private local vault for thoughts, journals, plans, and mood history
- Thought Circle view for capturing and exploring active loops
- Local AI guide powered by Gemma
- Reflection, support, and next-step conversations
- Markdown-formatted guide replies
- Journal writing with microphone capture
- Daily notes, summaries, and journal reflections
- Mood Colorizer with a visual history graph
- Starter plans and actionable anti-looping chains
- First-run guide and model download with pause/resume support
- Runs on Android, iOS, Linux, macOS, and Windows
- No account or cloud connection required for core features

## Privacy

Thought Circle is designed to keep personal thoughts on the user’s device. The local guide runs on-device after the model is installed.

## Get started

Download the release package or clone the repository:

```bash
git clone https://github.com/ornab74/thought-circle.git
cd thought-circle
flutter pub get
flutter run
```

See [README.md](README.md) for platform setup, software rendering, release signing, packaging, and deployment instructions.
